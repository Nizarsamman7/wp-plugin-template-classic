Classic starter plugin: a service post type, settings, and a shortcode.

== Description ==

Use this when the site needs content in WordPress admin instead of a full React block UI.

* Custom post type `studio_service`
* Price label meta box
* Settings page for business name, phone, and email
* Shortcode `[studio_services]`

== Installation ==

1. Copy this folder to `/wp-content/plugins/studio-services`.
2. Activate **Studio Services**.
3. Add services under **Services**.
4. Put `[studio_services]` on a page.
